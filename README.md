# NSC-Migration-abm-pde
Data is available upon request. Data includes the DTI principal eigenvector map and fractional anisotropy map, which main_driver loads
Combination-treatment-1-2 folder contains the code files used to run the simulations for changes in the chemosensitivity, stochastic chemosensitivity parameter, and dw, which can all be changed in the main_driver file.
Combination-treatment 3 folder contains code files used to run the radiation therapy simulation, where the files overlap with the first two treatments except in main_driver and run_simulation where changes were made to account for boosts in MCP-1 concentration at tumor and NSC death is taken into account on days where radiation treatment is added.
